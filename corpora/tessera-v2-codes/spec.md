# tessera-v2-codes

## Source

TESSERA v2 embeddings (`v2-2B-L~beta1`, 2024) on Source Cooperative, with the CRS and transform of each tile from its landmask GeoTIFF.

## Sample

128 embedding dimensions of 512×512 pixels at 10 m, cropped from one tile.

## Representation

Quantised codes as published, int8. The embedding is code × the matching sample of `tessera-v2-scales`.
