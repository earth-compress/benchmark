# Security Policy

## Supported versions

Before the first stable release, security fixes are made on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue with exploit details or sensitive data.

Include the affected version, a minimal reproduction, the expected impact, and
any known workaround. If private reporting is unavailable, contact a maintainer
and ask for a private channel before sharing details.
