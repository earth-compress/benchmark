10 / 14

Adding a codec is one Python module

# earthcompress/codecs/mycodec.py
import mycodec
from ..spec import ArraySpec
from .base import lossless, unpack

class MyCodec:
    def __init__(self, spec: ArraySpec):
        self.spec = spec

    def encode(self, array):
        return mycodec.compress(array.tobytes())

    def decode(self, data):
        return unpack(mycodec.decompress(data), self.spec)

CONFIGURATIONS = (lossless("mycodec", "mycodec",
                           mycodec.__version__, MyCodec),)

Two methods

encode takes the array and returns bytes. decode gives the array back.

Found on its own

The runner loads every module in earthcompress/codecs/.

Bounded modes

FAMILIES for near-lossless and LOSSY for lossy. The codec receives tau.

11 / 14

Run it, then git diff

# get the benchmark
git clone https://github.com/earth-compress/benchmark
cd benchmark

# every codec on one corpus
uv run earthcompress corpora/s2-l1c-10m-4

# only yours
uv run earthcompress corpora/s2-l1c-10m-4 --codec mycodec

# against the published results
git diff corpora/s2-l1c-10m-4/results.csv
