The benchmark contains 585 samples in 27 corpora. The samples are hosted in the Hugging Face dataset earth-compress/benchmark and downloaded on first use. Each corpus directory has a build script, description and manifest.

Most samples are windows from published products. ERA5 samples are complete global fields. Clay samples are blocks of MajorTOM cells. For samples with several planes, the first axis holds bands, time steps or embedding dimensions.

Raw MB is the total uncompressed size in decimal megabytes. In the scale, offset column, 1, 0 means scale = 1 and offset = 0.

Catalog IDs such as COPERNICUS/S2 refer to Earth Engine collections. Each corpus's spec.md records its source, sample definition, representation and licence.

Rebuilding

Each manifest.csv lists every sample's source asset, CRS, geotransform, dates and bands. To rebuild a corpus, run

uv run --extra corpus python corpora/<corpus-id>/build.py build

The command checks each sample against its input_sha256. Earth Engine collections require an authenticated account. ERA5 requires a Climate Data Store account that has accepted the ERA5 licence.
